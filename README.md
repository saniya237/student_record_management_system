# Student Record Management System

Module 2 internship project demonstrating Python functions, file handling, CSV/JSON, lambda functions, list comprehensions, virtual environments, exception handling, and CRUD operations.

## Features
- Create, read, update and delete student records
- Search by name, course or email
- Sort by marks using a lambda function
- Store records in both JSON and CSV
- Input validation and exception handling

## Run
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate
python student_record_management.py
```

No external packages are required.
